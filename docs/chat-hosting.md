# Website chat

The `/ai-chat` page calls the same site's `/api/ai/chat/*` Python routes.
Replies are generated by the site's rule-based research engine, with optional
public market feeds. This is not a general-purpose language model or browser-local AI.
Feed outages still allow replies from stored facts.

## Hosting configuration

- Run the FastAPI website with a writable persistent volume.
- Set `LOKI_CHAT_DB_PATH` to a SQLite file on that volume.
- Set `LOKI_CHAT_SESSION_SECRET` to a long randomly generated secret, identical
  across workers. Changing it invalidates existing sessions. Without it, sessions
  last only for the current process and cannot be shared across workers.
- Ordinary visitors need only a display name. For operator actions, configure
  `LOKI_CHAT_ADMIN_CODE` and enter it under Operator access with the operator name.
  A name alone never grants privileges.
- `LOKI_CHAT_CODE` optionally locks the whole room. Leave it unset for open chat.
- Use HTTPS. Put a shared rate limiter at the reverse proxy for multi-worker
  hosting; the built-in 60 POSTs/minute/IP limiter is per process.

Conversation history is scoped to a signed browser session. Public market facts
and operator-taught facts remain shared. Leaving the room ends access to that
session's history. Drafts and remembered display names are saved on the device.
