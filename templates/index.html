RULES FROZEN
01
Market condition

Potential uptrend: close is above the 100-bar simple moving average, and the 50-bar average is above the 100-bar average.

02
Entry trigger

When flat, that condition is true at a bar close. Enter long at the next bar open.

03
Exit trigger

Exit at the next bar open after a close below the 50-bar average or a close 5% below entry. Close any remaining position at the final bar.

i The code uses only information available at each bar close. Next-bar fills reduce same-bar lookahead.

PAPER AGENT CANDIDATES · ALSO FROZEN
20-bar breakout

Enter next bar after close breaks above the prior 20-bar high with SMA50 above SMA100. Exit next bar below SMA20 or after the shared 5% close stop.

Pullback reclaim

In the same confirmed uptrend, enter next bar when close crosses back above SMA20. Exit next bar below SMA50 or after the shared 5% close stop.

REAL MARKET · REAL MODE LOCKED

Live execution is not connected.

This preview has no secure broker adapter, account authorization, or order-routing endpoint. Broker secrets must live server-side. Live mode would also need a symbol allow-list, position and loss limits, paper sign-off, a kill switch, and an explicit per-session confirmation.

View what is needed to unlock real mode
  • A named broker and supported market-data feed.
  • Secure server-side key storage and account-read permissions.
  • Hard limits for order size, daily loss, allowed symbols, and open positions.
  • Verified paper logs and a one-click emergency stop.
  • Separate confirmation before every live session.
