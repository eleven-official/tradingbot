## 🎓 Tips for First Use

1. **Install dependencies first:**
   ```powershell
   pip install PyQt6 pyqtgraph pandas numpy alpaca-py yfinance python-dotenv
   ```

2. **Create .env file:**
   ```env
   ALPACA_API_KEY=your_key
   ALPACA_SECRET_KEY=your_secret
   ALPACA_BASE_URL=https://paper-api.alpaca.markets
   ```

3. **Start in Paper Mode:**
   - Test thoroughly before live trading
   - Build confidence with the system

4. **Train the AI:**
   - Click "Train AI" when you first load data
   - Aim for 80%+ reliability

5. **Understand signals:**
   - Read the reasoning
   - Check confidence level
   - Don't blindly follow
