## 🐛 TROUBLESHOOTING

### Issue: Desktop shortcut not appearing
**Solution:**
1. Run: `CREATE_LOKI_SHORTCUTS.bat`
2. Check desktop for "LOKI" icon
3. Refresh desktop (F5)

### Issue: "PyQt6 required" error
**Solution:**
```powershell
pip install PyQt6 pyqtgraph pandas numpy alpaca-py yfinance
```

### Issue: ".env file missing"
**Solution:**
Create `.env` file with:
```env
ALPACA_API_KEY=your_key_here
ALPACA_SECRET_KEY=your_secret_here
ALPACA_BASE_URL=https://paper-api.alpaca.markets
```

### Issue: Shortcut opens wrong version
**Solution:**
1. Delete old shortcuts
2. Run: `CREATE_LOKI_SHORTCUTS.bat`
3. New shortcuts will point to v7.0
